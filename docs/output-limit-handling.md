# 出力上限による回答打ち切りへの対応

2026-09-07。

- 推論強度「高」の助言は最大8,192トークンを要求する。「低」は従来の2,048、低設定の `/flow` は3,072を維持する。取得できたモデル固有の出力上限が小さければ、その値までに抑える。
- `finish_reason` が `length` / `max_tokens` の応答は、不完全な回答として出力上限専用のエラーを表示する。JSONとして成立していても完成した回答とは扱わず、同条件で形式修正を自動再送しない。
- OrcaRouterで本文がnullのまま `length` となった場合も、終了理由と利用量を保持する。推論過程の本文を回答として転用しない。
- 利用量はエラー判定前に記録し、接続を維持する。自動助言は既存の失敗時ルールに従って停止する。
- 通常の形式不備に対する修正は従来どおり1回までとし、高強度の出力枠を維持する。
- VS Codeの「表示 → 出力」で `NaviCom Diagnostics` を選ぶと、応答の終了理由、要求した出力枠、トークン数、リクエストID、所要時間、HTTPエラーの種別・コード等を確認できる。プロンプト・回答本文・APIキーは記録しない。
- 赤い通知の表示時間を10秒へ延長する。

出力枠の増加は実際の生成量を保証しない。有料モデルでは生成量に応じて使用量が増える可能性がある。タイムアウト値と日次トークンガードは変更しない。
