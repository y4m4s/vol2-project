# 20. つまずいたときの支援（Phase 3b）

Phase 3a の検知と、介入するかどうかの判断を分離する。検知は引き続きローカルで行い、判定専用のLLM呼び出しは追加しない。

## 設定と動作

学習プロファイルの「つまずいたときの支援」で有効にする。`stuckInterventionEnabled` は既定 false。`stuckDetectionEnabled` も有効なときだけ使う（検知が「記録しない」の間は、設定画面で選べない）。既存の保存値は記録のみのまま移行する。

| モード | Struggling になったとき |
|---|---|
| 必要時 | ホーム・会話画面の入力欄の上に相談チップ（「相談する」）を1つ表示する。クリックするまでLLMを呼ばない |
| 常時 | `AdviceScheduler.requestReevaluation()` で再判定を予約する。既存の待機・クールダウン・入力中停止・一時停止・接続条件を適用する |

一時停止は常時モードの自動生成に適用する。常時モードを一時停止してから必要時モードへ切り替えた場合も、必要時モードのローカル提案は表示する。

比較モードが suggest で比較が適用可能なら比較チップ、auto なら通常の相談に短い比較背景を添える。off / onRequest は、つまずきの相談自体はできるが比較背景は自動で付けない。比較の判断は既存の `ComparisonPolicy` に従う。

画面に表示するのは現在の文書についての提案だけ。入力中は新しいチップへ差し替えない。解消・除外・対象文書の変更時は取り下げ、クリック時も現在の論題と除外設定を確認する。対象行を開いて現在の文脈を集め直し、準備後・生成後に文書が変わっていれば破棄する。送信前の確認は、質問を会話に追加する前に行う。破棄したときは、自動で作った質問を会話から取り除き（空になった新しい会話は残さず、元の画面へ戻す）、理由を状態メッセージで表示する。

生成開始には Struggling を要求する。生成中にスコアが減衰して Watching / Calm へ移っただけなら、論題と文書が有効な限り回答を表示・保存し、陳腐化として数えない。論題の消失、除外、支援の無効化、対象文書の変更では回答を破棄する。

## 状態と頻度

`LearningSupportCoordinator` が文書URI＋論題IDの組ごとに `idle / offered / scheduled / inFlight / done` と試行回数を管理する。検知器の Calm / Watching / Struggling は変更しない。

- 提案表示だけでは介入間隔を消費しない。表示中は同じ論題を重複提示しない。
- 成功、no_advice、キャンセル、却下で完了とし、論題をまたいで10分のクールダウンを設ける。同じ論題には再介入しない。
- 送る文脈がない場合と、同じ論題・同じ文脈で相談済みの場合（重複抑止）は完了とするが、AIを呼んでいないのでクールダウンは設けない（`nothing_to_send`）。
- 中断ボタンで完了にするのは生成中の論題だけ。予約だけの論題は別の相談を中断しただけなので、予約を外して通常の間隔の後に予約し直す。
- 通信エラー（AIへの要求の失敗）は初回＋再試行1回まで。再試行まで既存のリクエスト間隔以上待つ。既存の通信エラーによる常時モード停止も維持する。
- 陳腐化は試行回数から除外するが、2回で打ち切る。
- 一時停止・切断・モード変更で破棄された予約は試行として数えず、条件が戻ったときに再評価する。送信前に止めたもの（日次上限、処理中、準備中の切断、設定の変更など）も `skipped` として試行に数えない。
- 墓標が残っている間の再発では、介入済み・却下の記録を引き継ぐ。墓標の期限切れや文書の解放後は記録を破棄する。

## 自動助言への統合

再判定シグナルにはローカル専用の `topicKey` を持つ。発火時に論題が解消・除外・別文書になっていれば、そのシグナルを捨てる。操作によるシグナルもある場合は通常の助言として続行できる。

有効な再判定に限り、fingerprint に論題キーを加え、同じ文脈で一度 no_advice になった場合も1回だけ再判定できるようにする。通常の fingerprint は変更しない。

`AutomaticGuidanceObservation.struggle` に信号の種類、行範囲・診断コード、経過秒数だけを付ける。文書URI・ローカル論題IDは送らない。「推定を断定しない」「具体的な助けにならなければ no_advice」を指示する。自動助言の応答JSON契約は変更しない。送信予定は既存の「自動判断情報」で開示する。
