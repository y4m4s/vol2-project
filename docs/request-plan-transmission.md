# 送信予定と実際の送信内容の整合

2026-09-09 更新。

常時モードでは「自動判断情報」に発火理由・カーソル周辺・編集範囲・診断増減などを表示する。除外対象のファイルでは観測情報全体を送信しない。収集・分類・古い結果の扱いは [自動助言のフォーカス判定](15-automatic-guidance-focus.md) を参照する。

- 入力欄のコマンド、質問、追加コンテキストを送信予定の再計算へ渡す。コマンドの強度指定と文脈プリセット、`/next deep` の収集範囲も適用する。
- 選択範囲とアクティブファイル本文が両方ある場合、生成プロンプトは選択範囲を優先するため、本文カテゴリのチェックは外す。
- `PromptBuilder` が文字量を調整して組み込んだブロックから、送信カテゴリ・参照ファイルを判定する。プレビューと回答の保存用プランで同じ判定を利用する。
- チェックはその情報の一部以上が送信対象であることを示し、全文送信を保証しない。ファイル名・言語等の識別情報は本文カテゴリとは別に含まれることがある。
- プロジェクト概要、再利用ナレッジ、定型フィードバック傾向も一覧へ表示する。過去の会話履歴やフィードバック補足コメントは送信しない。
- 古い入力に対する非同期収集結果は採用しない。詳細収集前の仮プランや入力変更直後は、チェックを表示せず更新中とする。
- 編集内容・モデル等が変われば送信時に再計算する。事前表示は送信内容を固定する承認画面ではない。
- 参照ファイルのホバーカードは、共通ボタンの中央配置を上書きして左寄せにする。

検証対象: 選択範囲優先、モデル入力予算、コマンド別文脈、追加コンテキスト、プロジェクト概要、ナレッジ・評価傾向、遅延応答による表示の巻き戻り、Webview入力境界。
